# File types

- Markdown. *.md
- Text. 
    - *.txt
    - .gitignore
- Lisp-like
    - *.clj
    - *.cljs
    - *.cljc
    - *.edn
- Source code files
    - *.sh
    - .bashrc, .zshrc, .*rc
    - *.py
    - Makefile
    - *.toml
    - *.yaml, *.yml
    - *.js

Note that *.template files are treated like the filename minus ".template"
